# 01 - Linear advection

Introductory experiments for the 1D linear transport equation.

Implemented ideas:
- explicit centered scheme (instability demonstration);
- Lax-Friedrichs;
- upwind discretisation;
- finite-volume interpretation of upwind;
- periodic Lax-Friedrichs vs upwind comparison.

These scripts establish CFL reasoning, stability, numerical diffusion, periodic boundaries, and the finite-volume viewpoint used in later modules.
