# Reproducibility and run guide

All numerical code is written in MATLAB. Run each module from its own folder so that generated figures and intermediate files remain local to the corresponding experiment.

## 1. Linear advection

Folder: `methods/01_linear_advection/`

Recommended order:

```matlab
TEcentered       % intentionally demonstrates instability
TELaxFriedrichs
TEUpwind
TEupwindFV
```

For the periodic comparison:

```matlab
cd periodic_comparison
CompararLaxUpwind
```

## 2. Burgers equation - first-order schemes

Folder: `methods/02_burgers_first_order/`

```matlab
prueba_exact_burgers
comparacion_conservacion_burgers
```

The second script compares conservative and non-conservative discretisations and multiple first-order fluxes against the entropy solution.

## 3. Burgers equation - MUSCL-Hancock

Folder: `methods/03_burgers_muscl_hancock/`

Representative scripts:

```matlab
main
compare_godunov_muscl
compare_limiters
experiment_rarefaction
experiment_smooth_convergence
```

The smooth experiment is the main convergence study and compares Minmod, Van Leer, Van Albada, and Superbee.

## 4. 1D Euler equations - Sod shock tube

Folder: `methods/04_euler1d_muscl_hll/`

Run in this order when reproducing the first-order/second-order comparison:

```matlab
hll_primer_orden_sod
muscl_hancock_sod
comparacion_hll_muscl
```

Then run the broader studies:

```matlab
comparacion_limitadores_sod
zooms_discontinuidades_sod
estudio_refinamiento_sod
```

`comparacion_hll_muscl.m` reads the `.mat` files generated by the first two simulations. Generated `.mat` files are intentionally ignored by Git.

## 5. MUSCL-Hancock vs ADER4

Folder: `methods/05_ader4_linear_advection/`

```matlab
main_comparison      % 50-period long-time propagation
convergence_study    % N = 20 ... 640
error_vs_periods     % growth of error with propagation time
```

## Notes on MATLAB compatibility

The source uses modern MATLAB features such as `arguments`, `exportgraphics`, string scalars, and tables. The exact MATLAB release used during the internship was not recorded in the supplied archive, so no unsupported version claim is made here.
